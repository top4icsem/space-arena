# Що саме зробити після завантаження ZIP — лабораторна №2

**1.** Розпакуй ZIP. Відкрий отриману папку `space-arena-lab-02` у Terminal (Mac: правий клік на папці → New Terminal at Folder, або введи `cd ` і перетягни папку у вікно термінала). **Не створюй новий GitHub-репозиторій** — треба використовувати попередній, куди викладав лабораторну №1.

**2.** У папці виконай:

```bash
node -v
npm install
npm run format
npm run check
npm run dev
```

Після `npm run dev` відкрий `http://localhost:5173` або іншу адресу, яку покаже Vite. Якщо команда `npm run check` завершується помилкою, скопіюй мені її повний текст — перед публікацією треба розібратися.

**3.** Перевір руками: WASD політ; `Space` стрільба; `Shift + Space` homing; зелений ромб pickup; попадання в астероїд, червоний корабель, вибух і score; отримання шкоди та 2-секундний респаун; P пауза, R перезапуск. У DevTools → Console не повинно бути червоних помилок.

**4.** Перевір Git-історію і старий тег:

```bash
git status
git log --oneline -3
git tag -l
git remote -v
```

Архів продовжує локальний `.git` з ЛР №1; має бути `lab-01` і `lab-02`. Перевір, що `origin` вказує саме на **той репозиторій**, куди здавав першу ЛР. Якщо `git remote -v` порожня, додай його URL (скопіюй з GitHub сторінки свого старого репозиторію):

```bash
git remote add origin https://github.com/ТВІЙ-ЛОГІН/НАЗВА-СТАРОГО-РЕПО.git
```

Якщо GitHub уже містить твої нові коміти, які відсутні у ZIP, **не роби `push --force` для `main`** — спершу звір історії, щоб нічого не затерти. За потреби перенеси зміни ЛР №2 у свій поточний клон репозиторію замість заміни історії.

**5.** Якщо після `npm run format` змінилися файли:

```bash
git add .
git commit -m "Verify and finalize lab 02"
git tag -f lab-02
```

Якщо змін немає, комітити ще раз не потрібно. Потім:

```bash
git push -u origin main
git push origin lab-01
git push origin lab-02
```

**6.** На GitHub переконайся, що в репозиторії видно нові файли `src/sim/world.js`, `src/sim/ship-class.js`, `src/sim/behaviors.js` і тег `lab-02`. На здачу дай посилання на **старий публічний GitHub-репозиторій** і вкажи тег `lab-02`.

**7.** Підготуй демонстрацію на 5 хв: готовий текст/порядок у `docs/defense-lab-02.md`, відповіді у `docs/reflection-lab-02.md`. Локальний README з ЛР №1 збережено у `docs/lab-01-readme.md`.

**ВАЖЛИВО:** архів підготовлено локально; я не можу опублікувати його у твоєму GitHub-акаунті без доступу. `npm install` у середовищі підготовки ZIP не завершився через недоступність registry, тому `npm run check` треба обов'язково виконати на твоєму Mac перед здачею.
