# Як додати ЛР №4 до твого готового Space Arena (Mac / VS Code)

**Не створюй новий GitHub-репозиторій і не видаляй `.git`.** Продовжуємо вже здані ЛР №1–3.

1. Відкрий у VS Code стару папку, з якої ти завантажував ЛР №3 (раніше `space-arena-lab-02`). Термінал повинен бути відкритий саме в ній.
2. Перевір `git status` — бажано `working tree clean`, щоб усі правки ЛР №3 уже були закомічені.
3. Завантаж ZIP `space-arena-lab-04-update.zip` у папку `~/Downloads` та виконай **у старому репозиторії**:

```bash
unzip -o ~/Downloads/space-arena-lab-04-update.zip
node apply-lab04.mjs
```

Скрипт **перенесе** старі `src/`, `public/`, `tests/`, `index.html` до `client/`; залишить `.git` і коміти; збереже старий README у `docs/lab-03-readme.md`; додасть новий `server/`, оновить npm workspaces, прибере статичний `/api/rooms` із минулої лаби та старий lockfile.

4. Встанови пакети і запусти **обидва сервери однією командою**:

```bash
npm install
npm run format
npm run check
npm run dev
```

5. Відкрий адресу Vite з термінала **у двох браузерних вікнах**. Після loading в обох вибери `Orion Belt`, введи різні імена `Anna`/`Bohdan`, натисни Join. Обидва бачать однаковий список гравців і чат. Кораблі й постріли лишаються локальними (мережева фізика — ЛР №5).
6. Після успішного `npm run check` і ручної перевірки:

```bash
git status
git add -A
git commit -m "Lab 04: Node HTTP, WebSockets, rooms and streaming logs"
git tag lab-04
git push origin main
git push origin lab-04
```

7. **Здай те саме посилання**: https://github.com/top4icsem/space-arena . Перевір на GitHub папки `client/`, `server/`, тег `lab-04` і старі теги `lab-01`, `lab-02`, `lab-03`.

**Якщо з'являється `Cannot find module 'ws'`:** виконай `npm install` саме в корені. Якщо Vite повідомляє `ECONNREFUSED /api`, перевір Node-сервер на порту 3000. GitHub зберігає код, але сам Node-сервер не запускає.

Зламаний для лабораторного сценарію JSON залишається у `client/public/assets/data/broken.json` і виключений з Prettier. Не виправляй його.
