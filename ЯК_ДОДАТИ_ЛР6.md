# Як додати лабораторну №6 у старий проєкт на Mac

1. Відкрий у VS Code **стару папку `space-arena-lab-02`**, де вже ЛР №5. **Не створюй новий репозиторій!**
2. Зупини `npm run dev` через **Control + C**. Переконайся, що поточний код ЛР №5 вже в GitHub, і немає важливих незакомічених змін: `git status`.
3. Скачай `space-arena-lab-06-update.zip` у Downloads.
4. У терміналі старої папки введи:

   ```bash
   unzip -o ~/Downloads/space-arena-lab-06-update.zip
   node apply-lab06.mjs
   npm install
   npm run format
   npm run typecheck
   npm run check
   npm run dev
   ```

   `apply-lab06.mjs` видаляє **тільки старі `.js` двійники** мігрованих `.ts` модулів, зберігає твій README ЛР №5 у `docs/lab-05-readme.md` та **не чіпає `.git`**. Повторний запуск не видалить архівований README.

5. Відкрий сайт за портом Vite, який показує термінал. У двох вкладках зайди під `Player1` і `Player2` у **ту саму** кімнату, перевір рух, постріли, чат і HUD. В лобі мають залишатися всі три стартові кімнати.
6. Коли `npm run check` пройшов і дві вкладки працюють, зупини сервер і виконай:

   ```bash
   git add -A
   git commit -m "Lab 06: strict TypeScript simulation and Zod protocol"
   git tag lab-06
   git push origin main
   git push origin lab-06
   ```

7. Здавай той самий GitHub: https://github.com/top4icsem/space-arena/tree/lab-06

**Важливо:** Node.js 22.16+ потрібен для запуску `.ts` через `--experimental-strip-types`. Якщо `npm run check` видає помилку, не роби `git push` до виправлення. Не запускай сервер ЛР №5 паралельно, бо порт 3000 буде зайнятий.
