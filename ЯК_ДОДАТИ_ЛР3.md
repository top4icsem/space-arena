# Як установити ЛР №3 ПОВЕРХ уже наявної папки ЛР №2 (Mac / VS Code)

Це **ZIP-оновлення**, а не новий репозиторій. У ньому немає `.git`. Воно містить тільки **нові** та **змінені** файли; недоторкані модулі/документи ЛР №1–2 залишаться у твоїй папці.

## Крок 1 — Відкрий старий репозиторій, який уже має origin

У VS Code відкрий **ту саму папку**, з якої ти щойно відправив ЛР №2 у GitHub (`space-arena-lab-02`, або як ти її назвав). Виконай:

```bash
git status
git remote -v
git tag -l
```

Переконайся, що `origin` — `https://github.com/top4icsem/space-arena.git`, є теги `lab-01` і `lab-02`, немає незбережених змін. Якщо є власні незбережені правки, спочатку збережи/закоміть їх, щоб ZIP їх не затер.

## Крок 2 — Розпакуй ZIP у корінь цього самого проєкту

**Варіант через Terminal (найпростіший):**

```bash
cd /ШЛЯХ/ДО/ТВОЄЇ/ПАПКИ/space-arena-lab-02
unzip -o ~/Downloads/space-arena-lab-03-update.zip
```

`cd` має вести саме в стару папку, **де лежать `index.html`, `src/`, `package.json` і `.git/`**. Команда розпакує з ZIP кореневі `src/`, `public/`, `docs/` та замінить тільки потрібні файли. **Не видаляй `.git`, не роби `git init`, не створюй новий репозиторій і не копіюй теги з іншої папки.**

**Важливо для Finder:** не погоджуйся на **повну заміну папки `src`**: тоді можуть зникнути незмінені модулі ЛР №1–2! Найбезпечніше — саме команда `unzip -o` з цього кроку: вона додає файли й не видаляє інші.

## Крок 3 — Запусти

```bash
npm install
npm run format
npm run check
npm run dev
```

У браузері відкрий адресу, яку покаже Vite (найчастіше `http://localhost:5173`). Має бути **завантаження 8 ресурсів → лобі → вибір кімнати та Join → політ і стрільба зі звуком**. Перевір тестову аварію: `http://localhost:5173/?failure=404` → Retry.

**Не пропускай перевірку у себе:** інтернет для `npm install` та повна Vite-збірка не були доступні в середовищі підготовки. Якщо `npm run check` завершиться з помилкою, збережи вивід — це треба усунути до здачі.

## Крок 4 — Опублікуй ЛР №3 у ТОМУ САМОМУ GitHub

```bash
git status
git add .
git commit -m "Lab 03: async assets, lobby and Web Audio"
git tag lab-03
git push origin main
git push origin lab-03
```

Перед `git tag lab-03` переконайся, що новий коміт створено. Якщо тег уже існує, не перевизначай його без перевірки. **Не використовуй `git push --force`.**

## Крок 5 — Здача

На `https://github.com/top4icsem/space-arena` повинні бути `src/assets/`, `src/audio/`, `src/lobby/`, `public/assets/`, новий `README.md` та три теги: **`lab-01`, `lab-02`, `lab-03`**. Викладачу здаєш **те саме посилання**, а на п'ятихвилинному захисті показуєш `loading → lobby → постріл зі звуком`.
