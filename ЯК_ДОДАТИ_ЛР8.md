# Як додати ЛР №8 до того самого Space Arena проєкту

1. Відкрий у VS Code папку `space-arena-lab-02` з ЛР №7. Переконайся, що `git status` не показує незбережених змін у tracked-файлах.
2. Розпакуй вміст **цього** ZIP **всередину цієї папки** (не створюй новий репозиторій).
3. У Terminal виконай:

```bash
node apply-lab08.mjs
npm install --include=optional
npm run format
npm run check
CI=true npm run test:e2e
```

4. Docker Desktop на Mac повинен бути запущений. Перевірка Docker:

```bash
npm run test:docker
docker compose up -d --build
curl http://127.0.0.1:3000/health
curl http://127.0.0.1:3000/ready
curl http://127.0.0.1:3000/metrics
docker compose down
```

5. Після успішних перевірок відкрий `docs/lab08-deploy.md` — там інструкції з GHCR, Fly.io, секретами, HTTPS/WSS, тегами `lab-08` і `v1.0.0` та переліком доказів для захисту.

**Не пуш теги до того, як npm check, E2E та Docker smoke будуть зеленими!**

Це оновлення для ЛР №7, а не новий репозиторій. Скрипт не перезаписує `.git`, не змінює теги, зберігає історичну README попередніх робіт. Живий хостинг і два зовнішні RTT не можуть бути перевірені до реального розгортання.
