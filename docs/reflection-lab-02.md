# Lab 02 — Reflection (короткі відповіді на захист)

**1. Чим відрізняються клас, екземпляр і прототип?** Клас описує спосіб створення об'єктів та їхні методи; `new Ship()` створює екземпляр з власними `id`, координатами й HP. Методи класу розташовані на `Ship.prototype`. Якщо властивість відсутня на екземплярі, JavaScript шукає її вздовж прототипного ланцюжка. `Ship.prototype → Entity.prototype → Object.prototype → null`. Глибина `extends` у власному коді — один рівень.

**2. Чому `this` ламається при `addEventListener('keydown', ship.fire)`?** Передається посилання на функцію, а не виклик через `ship`. DOM під час виконання listener підставляє `this` як `currentTarget`, а не корабель; тому метод спробує читати `position` та `fireCooldown` у `window`. У strict-виклику `const f=ship.fire; f()` контекст взагалі `undefined`. Виправлення: `ship.fire.bind(ship)` або стрілка `() => ship.fire()`; у грі метод викликається як `game.player.fire()`.

**3. Чому `Map` краще за масив для `World`?** `Map` дозволяє знайти/позначити об'єкт за `id`, не перебираючи весь масив, і зберігає порядок вставляння. Для фільтра за видом служить генератор `*ofKind(kind)` без проміжного масиву. Можна було б використати масив, але керування ID було б менш зручним. `Set` є в input-модулі для стану клавіш, також він добре підходить для набору унікальних ID; `Map` потрібен саме для пари ID → Entity.

**4. Навіщо `dead`-позначка і `sweep`?** Видаляти об'єкт під час ітерації небезпечно для подальшої логіки зіткнень. `despawn()` лише змінює `alive=false`; `sweep()` наприкінці `World.step` видаляє всі позначені. Колізії перевіряють `alive`, тому одна куля не знищує кілька цілей за один кадр.

**5. Чому композиція краща за `HomingAsteroid extends Asteroid` і `HomingBullet extends Bullet`?** Самонаведення — одна незалежна здібність для різних сутностей. Через `homing({target,...})` її повторно використовують і кулі, і астероїди. `pickup` — просто Entity з компонентом `collectible`, без створення штучної підгілки кораблів. Мінус: потрібна явна дисципліна контрактів `kind`, `update`, `collect`.

**6. Що означає чистий метод у `Vector2`?** `v.add(w)` повертає новий `Vector2` та не змінює `v` або `w`. Це спрощує тести й відтворення результатів, бо одна й та сама операція з однаковими аргументами дає однакове значення. У цій роботі вектор `Object.freeze` зроблено незмінним.

**7. Як працює колізія й яка складність?** Два кола перетинаються, якщо квадрат відстані між центрами не більший за квадрат суми радіусів; у тороїдальній арені відстань береться через найкоротший шлях, враховуючи край. `resolveCollisions()` перевіряє пари сутностей O(n²), не враховує в колізіях візуальні частинки. Для невеликого навчального світу цього достатньо; при великих n можна додати spatial hashing.

**8. Як TTL і респаун пов'язані з циклом?** TTL зменшується на `dt` у `World.step`, при нулі куля позначається мертвою й прибирається в `sweep`. При загибелі гравця `Game` ставить таймер 2 с і в наступних кроках віднімає `dt`; ніякого `setTimeout` немає, отже пауза гри також зупиняє відлік.

**9. Чому `Ship.fire()` з носа?** Обчислюємо напрям `Vector2.fromAngle(angle)`, додаємо зміщення 34 px від центру і суму швидкості корабля та початкової швидкості кулі. Так куля не виникає всередині власного кола й її рух наслідує інерцію корабля.
